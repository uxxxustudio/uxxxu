왜 이 프로젝트가 필요했는가

시각·청각장애인은 주변 환경을 인지하고 타인과 의사소통하는 과정에서 다양한 제약을 경험합니다. 기존 보조기기는 특정 기능에 한정되어 있거나 여러 기기를 함께 사용해야 하는 불편함이 있었으며, 실시간 정보 전달과 접근성 측면에서도 개선이 필요했습니다.

사용자와 시장을 이해하기 위한 조사

접근성과 웨어러블 서비스 UX를 분석하기 위해 국내외 보조기기 및 AI 서비스 사례를 조사하고, 사용자 인터뷰를 통해 서비스 이용 과정에서의 주요 요구사항과 인사이트를 도출했습니다.

Service Structure

사용자 요구사항을 서비스 구조로 연결

사용자 요구사항을 바탕으로 서비스 구조와 화면 계층을 정의하고 Information Architecture를 설계했습니다. 서비스의 주요 기능과 화면 간 관계를 명확하게 정의하여 이후 UX/UI 설계의 기반을 구축했습니다.

UX Design

화면과 기능을 구체적인 UX로 설계

Information Architecture를 기반으로 각 화면의 역할과 기능을 정의하고, 화면 간 관계와 사용자 흐름을 구체적인 화면 설계로 발전시켰습니다.

Screen Definition

화면 정의

각 화면에서 제공해야 하는 기능과 정보의 우선순위를 정의하여 화면 간 관계와 사용자 흐름을 명확하게 설계했습니다.

Wireframe

Low-Fidelity Wireframe

Information Architecture를 기반으로 주요 기능의 화면 구성과 사용자 흐름을 저충실도 와이어프레임으로 구체화했습니다.

Outcome

UX 구조와 화면 설계를 통해 서비스의 기반을 구축했습니다.

사용자 요구사항을 바탕으로 서비스 구조와 Information Architecture를 정의하고, 주요 기능의 화면 구조와 사용자 흐름을 구체화했습니다. 이를 통해 웨어러블 디바이스와 모바일 애플리케이션이 연결되는 서비스 경험의 기반을 구축했습니다.
