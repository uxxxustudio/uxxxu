01 / PROJECT

신화를 디지털 경험으로 확장하다.

Project Overview

‘설문대할망 전시관’은 제주 여신 신화인 설문대할망 이야기를 중심으로, 제주의 자연, 여성성, 신화적 상상력을 현대적으로 풀어낸 전시 콘텐츠입니다.

전시 콘텐츠의 성격에 따라 감성적인 영상 콘텐츠부터 인터랙티브 키오스크와 미니게임까지 다양한 디지털 경험을 설계하고 디자인했습니다.

캐릭터 제작을 제외한 화면 구성, UI, 콘텐츠 비주얼 및 사용자 경험 설계를 담당했습니다.

01

Storytelling

제주의 신화와 자연을 현대적인 시각 언어로 재해석

02

Interaction

관람객이 직접 참여하고 경험할 수 있는 인터랙션 설계

03

Visual System

돌, 물결, 빛 등의 상징 요소를 콘텐츠 전반의 그래픽 언어로 확장

02 / HŎBŎK

빛으로 표현한
제주인의 이야기

허벅에서 흘러나오는 빛 입자를 통해 자연과 인간의 조화로운 연결을 표현했습니다. ‘담다’라는 키워드를 중심으로 제주의 삶과 자연을 현대적으로 시각화했습니다.

TRANSPARENT OLED DISPLAY

허벅 영상 디자인

제주 허벅 전시관에 설치된 투명 OLED 디스플레이 영상 콘텐츠를 디자인했습니다.

03 / JIJANG BONPULI

전통 설화를
현대적인 영상으로

지장본풀이의 전통 설화를 현대적인 감각으로 재해석하고, 미니멀리즘과 몽환적인 분위기를 중심으로 컨셉 영상을 디자인했습니다.

CONCEPT VIDEO

지장본풀이

리듬감 있는 모션과 그라데이션 컬러, 원과 면을 활용해 설화의 신비롭고 초월적인 분위기를 표현했습니다.

04 / SHINHWAJI

관람객이 직접 참여하는
인터랙티브 전시

‘소망의 돌’을 중심으로 구성된 인터랙티브 체험 콘텐츠입니다. 6개의 미니게임을 완료하면 제주 돌을 획득하고, 디오라마 위에 돌을 쌓아 소망을 완성합니다.

05 / INTERACTIVE GAMES

제주 신화를
직접 플레이하다.

제주 지역의 지형과 설화를 각각의 게임 방식으로 재해석해 관람객이 자연스럽게 이야기를 경험할 수 있도록 구성했습니다.

GAME 01

등경돌에 불을 밝혀라!

숲 속에 숨어 있는 불을 든 캐릭터를 찾아 선택하고, 등경돌에 불을 붙여 마을에 빛을 밝히는 과정을 체험할 수 있도록 디자인했습니다.

GAME 02

범섬 구멍을 뚫어라!

설문대할망이 바다에 돌을 던져 범섬을 만들었다는 설화를 바탕으로, 돌을 정확히 던져 구멍을 만드는 체험형 게임입니다.

GAME 03

우도에서 빨래를 하자!

우도를 커다란 빨래판으로 재해석하고, 전통 빨래 방식의 요소를 게임 인터랙션으로 연결했습니다.

GAME 04

엉장메코지 다리를 놓자!

하늘에서 떨어지는 돌을 정확한 위치에 놓아 다리를 완성하는 방식으로 엉장메코지 설화를 직관적으로 체험할 수 있도록 디자인했습니다.

GAME 05

고내봉에서 공기놀이 하자!

설문대할망이 돌을 던져 만든 봉우리라는 설화를 바탕으로, 돌을 공기놀이 방식으로 받는 인터랙션으로 재해석했습니다.

06 / DESIGN CONCEPT

하나의 신화,
서로 다른 경험

‘허벅’을 모티프로 한 서정적 공간, 설문대할망의 삶을 다룬 지장본풀이 시각화 콘텐츠, 그리고 체험형 ‘신화지’ 게임까지 각기 다른 주제의 전시에 맞춰 콘텐츠를 구성했습니다.

콘텐츠의 성격에 따라 감성적인 영상, 상징적인 그래픽 언어, 직접 참여하는 인터랙션 등 서로 다른 경험 방식을 설계했습니다.

각 콘텐츠는 서로 다른 형태를 가지고 있지만, 돌·물결·빛과 같은 제주와 설문대할망의 상징 요소를 통해 하나의 전시 경험으로 연결되도록 디자인했습니다.
